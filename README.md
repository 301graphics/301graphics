# 301 Graphics — website v10

Next.js 14 (Pages Router) + Tailwind + Framer Motion. Deployed on Vercel from GitHub.

```bash
npm install
cp .env.example .env.local   # optional: add keys
npm run dev                  # http://localhost:3000
npm run build                # production build (must pass before pushing)
```

See DEPLOY.md for the deploy steps and the environment variables that switch on the quote form email, Calendly, GA4, reviews link and Instagram feed.
